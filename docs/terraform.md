# Серверы из кода: Terraform

Машины в Timeweb Cloud описаны в `infra/terraform/` (провайдер `timeweb-cloud/timeweb-cloud`).
Terraform отвечает за саму машину: имя, тариф (vCPU, память, диск), ОС при создании, IPv4.
Что стоит внутри (Node, Caddy, Postgres, службы, туннели) — по-прежнему `infra/game/` через `game-deploy`;
следующий шаг — Ansible (настройка машины ролями, сухой прогон против прода перед переходом).

## Как пользоваться

- **Поменять тариф** — `preset` в `infra/terraform/servers.tf`. PR → прогон `infra-terraform` показывает план
  (Summary прогона: «`preset_id`: 6807 → 6809»). После слияния — Actions › `infra-terraform` › Run workflow,
  `apply` = true. Смена тарифа **перезагружает сервер**: матчи и сайт рвутся на 2–3 минуты — применять ночью.
  После — запустить `game-deploy`: `setup.sh` пересчитывает потолок комнат и память под новую машину.
- **Новый сервер** — запись в `local.servers`. План покажет «создать» (и заказ IPv4 в Нидерландах).
  После `apply` — `game-deploy` с новой записью в матрице (или Ansible, когда будет).
- **Удалить сервер** — только вручную в панели Timeweb. Terraform удалять и пересоздавать не умеет нарочно:
  `prevent_destroy` на каждом сервере, и `summary.py` останавливает план с удалением.
- Тарифы и цены — `infra-check.yml` (шаг «S3 и серверы в Нидерландах»). Любая платная правка — с «да» владельца и ценой.

## Без состояния

Файл состояния (state) нигде не хранится. Перед каждым планом `discover.py` спрашивает у Timeweb,
какие серверы есть (имя → id), и Terraform подхватывает их блоком `import` — состояние собирается заново
из живого Timeweb. Плюсы: не нужен бакет (S3 ещё не куплен), в состоянии нет пароля root и VNC,
расхождения с панелью видны сразу. Цена: имена серверов уникальны (два с одним именем — ошибка `discover.py`),
а удалённую из кода запись Terraform просто забывает. Когда появится S3 (`docs/infra-plan.md › этап 2`),
можно перейти на `backend "s3"` — одна правка в `versions.tf`.

Поля, которые задаются только при создании или живут в панели (ОС, ключи, комментарий, DDoS-защита, зона),
у живых серверов не сравниваются (`ignore_changes`) — иначе подхваченный сервер «хотел бы» пересоздаться.

## Проверено

- Подхват трёх серверов — «3 to import, 0 to change, 0 to destroy»; смена `preset_id` — `update in-place`
  (не пересоздание); новый сервер — создание + IPv4. Прогон против заглушки API Timeweb (провайдер 1.8.4).
- `provision.py` (выкладка) больше не удаляет и не перезагружает живой сервер, у которого тариф не совпал
  с `SERVER_PRESETS` или SSH минуту не отвечал: это теперь только для только что созданных и без IPv4.
