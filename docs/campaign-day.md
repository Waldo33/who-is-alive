# Памятка на день рекламы

Коротко: накануне ночью — нагрузочный прогон, перед запуском — стоп-кран выкладок, в день — одна вкладка Grafana и телефон с тревогами. Ниже — что делать, если что-то пошло не так. План, из которого это выросло, — `docs/infra-plan.md` (этап 4).

## Накануне (ночью по Москве)

1. **Нагрузочный прогон против Москвы:** Actions → `load-test` → Run workflow → `target: prod`, `rooms: 120`, `seconds: 180`. Смотреть итог:
   - «комнат N из N» — все поднялись; «занято» > 0 — упёрлись в `MAX_ROOMS` (это нормально около 150 на 1 ГБ);
   - пинг p99 до 50 мс — хорошо, больше 150 мс — игроки почувствуют лаг;
   - в «Метрики Москвы»: свободной памяти больше 100 МБ, шаг p99 меньше 5 мс.
2. Если не хватило — увеличить сервер в панели Timeweb (это **перезагрузка**: идущие матчи оборвутся — только ночью), потом запустить `game-deploy` вручную: `setup.sh` пересчитает `MAX_ROOMS` и память службы под новый размер.
3. Проверить, что сторож молчит (нет «🔴» в чате тревог) и что записи AAAA у домена удалены.

## Перед запуском

- **Стоп-кран выкладок:** GitHub → Settings → Secrets and variables → Actions → Variables → `DEPLOY_FREEZE` = `1` (или `gh variable set DEPLOY_FREEZE --body 1`). Push в `main` больше не выкатывается; срочную правку — вручную: Actions → `game-deploy` / `web-deploy` → Run workflow. Выкладка и так не обрывает матчи, но в день залпа лучше ничего не менять.
- Открыть Grafana: `https://72-56-73-184.sslip.io/grafana/` → панель «серверы».

## Если что-то сломалось

- **«Площадка переполнена» у многих.** Сервер у потолка комнат: это защита, матчи идут. Быстро не лечится — только увеличение сервера (перезагрузка, см. выше) ночью или в затишье.
- **Игра не отвечает** (тревога «игровой сервер»): Actions → `infra-diag` покажет службы и логи. Откат на прошлую версию — по SSH на Москву (команды в начале блока выкладки `infra/game/setup.sh`): вернуть прежний цвет в `/etc/massovka/active-color`, запустить его, `caddy.sh`, а новый — в drain.
- **Сайт не открывается, игра работает:** откат сайта — вернуть прежний цвет в `/etc/massovka/web-active`, `systemctl start massovka-web@<цвет>`, `/opt/massovka/bin/caddy.sh`.
- **Бот молчит / не шлёт клипы** (тревога «бот через Москву»): туннель Нидерланды → Москва; он поднимается сам за минуту-две. Не поднялся за 10 минут — `infra-diag`.
- **После выкладки посыпались ошибки JS** — откатить сайт (выше) и разбираться спокойно.
