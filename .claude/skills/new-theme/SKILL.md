# Новая тема («площадка») на заданный сеттинг

Тема = **костюм толпы + локация + музыка + текстовки + (по желанию) «изнанка»** — внезапная смена облика посреди дубля со своим поведением толпы. Образец со всеми возможностями — `apps/web/src/game/themes/office.ts` («Клерки»: офис ↔ подвал). Простая тема без изнанки — `themes/kitchen.ts`. Устройство — `docs/architecture.md › Темы`.

Работай до конца сам (владелец пишет с телефона): исследование → концепт одним сообщением → код → проверка глазами → push → короткий отчёт с картинкой.

## 0. Цель: узнаётся за две секунды

Владелец хочет **максимальное сходство с источником**. Узнаваемость даёт не копия героя, а набор **сигнатур** источника, которые читаются в пикселях 12×16:

| Слой | Что даёт узнавание | Пример («Клерки») |
|---|---|---|
| Палитра | 2–3 цвета, которыми источник «окрашен» | офис — белый/серо-синий; подвал — ржавчина, огонь, бетон |
| Силуэт-типаж | одна-две детали костюма, видные на 12 пикс. | галстук + бейдж; голый торс + фингал |
| Предметы-иконы | 3–5 вещей, без которых сеттинга нет | жалюзи, кулер, ксерокс; бочка с огнём, груша |
| Поворот-изнанка | ключевой поворот/механика источника как событие дубля | «днём офис, ночью подпольный клуб» → свет мигнул, подвал |
| Действия толпы | эмоции и команды «Море волнуется» — характерные занятия сеттинга, в каждом облике свои | офис: «Шеф идёт!» (все в ноутбуки), кофе, перекур, звонок; подвал: стойка, скакалка, бой с тенью, бицепс |
| Звук | жанр, тембры, темп, динамика | тихий куплет / громкий перегруженный припев |
| Текст | мем-формула («снежный ком») своими словами | «Правило 1: не светись» |
| Гэг | одна деталь «для своих» | «25-й кадр» — на миг мелькает боец |

Сначала выпиши 10–15 сигнатур источника (поиском, если нужно), потом оставь те, что **читаются в 12×16 и на 180×260**, и разложи по слоям таблицы. Чем больше слоёв попало в источник, тем сильнее сходство — добирай им, а не копированием.

### Граница (держать всегда)

Сходство — через жанр, атмосферу, типажи и мем-формулы. **Не делаем**:
- конкретного персонажа франшизы в узнаваемом облике (его фирменная причёска + костюм + аксессуар вместе), его имени, имени актёра, названия фильма или бренда в игре; реальных людей;
- логотипов, вывесок с настоящими названиями, постеров;
- мелодий, риффов, вокальных линий и текстов песен — только жанр, темп, тембры, приёмы (тихо-громко, сёрф-эхо, восьмые басом); мелодия всегда своя;
- цитат длиннее короткой общеизвестной мем-формулы — и ту переформулируй под «массовку».

Если сеттинг держится на одном герое (как фильм о конкретном персонаже) — сделай **толпу его типажа** (клерки, бойцы, вожатые, грабители в одинаковых масках) и перенеси его фишку в изнанку/жест. Так и сказать владельцу в концепте одной строкой, без лекций.

## 1. Концепт — одним сообщением владельцу

Перед кодом пришли (SendUserMessage) коротко: название темы (ru/en), обычный облик и изнанка (если есть), кто толпа, 3–5 предметов, событие изнанки, **таблица действий по обликам** (что толпа делает на «замри», «прыжок», «танец» и эмоцию — занятия сеттинга, а не танцы: в офисе работают, пьют кофе, курят; в подвале — стойка, скакалка, бой с тенью), музыка (жанр + части + что меняется в изнанке), 2–3 текстовки. Не жди ответа, если владелец не просил согласовать — начинай.

## 2. Правила — `packages/game-core/src/themes.ts`

- `ThemeId` += id; `THEME_RULES` — **только в конец** (индекс уходит в сеть, порядок старых не трогать).
- Изнанка (по желанию): `twist: { firstSec, onSec, gapSec, max, emote, emoteMul }`. Образец: `{ firstSec: [14, 26], onSec: [14, 20], gapSec: [10, 16], max: 2, emote: 'jab', emoteMul: 4 }`. Хост сам шлёт событие `{ t: 'twist', on }`, не посреди команды «Море волнуется» (ни в стоп-кадре, ни пока толпа в позе — сразу после), новые включения не после начала сужения, к концу дубля — выключает.
- **Действия толпы делай в облике, а не в правилах** (§4.4): механика у всех тем одна — `freeze`/`jump`/`dance` (команды «Море волнуется») и эмоции `wave`/`dance`/`jump`; тема лишь задаёт, как они выглядят и называются. Так баланс и правило 2 (боты и игроки неотличимы по формату) не трогаются.
- `twist.emote` — только если в изнанке все должны делать **одно и то же** (тогда эмоция у всех подменяется этой); обычно не нужно — разнообразие дают свои анимации облика. `emoteMul` — насколько чаще толпа «живёт» в изнанке.
- Своя механика сверх изнанки — только детерминированно (Rng с зерном, игровое время), в `MatchSim`, с тестом в `test/core.test.ts`; любое новое поле события проверить на утечку «кто игрок».

## 3. Текстовки — `packages/game-core/src/locale/{ru,en}.ts`

- `themes` — название толпы (как «Кепки», «Клерки»), в конец, в обоих словарях. `Дубль 5 · {название}` ≤ 21 символа.
- `themeText[id]`: `intro` (тост через ~1 с после «Мотор!»), `twistOn`, `twistOff`; `crowd` — свои названия команд «Море волнуется» `{ freeze, jump, dance }` в обычном облике, `twistCrowd` — в изнанке (они должны совпадать с анимацией и иконкой облика). Каждая ≤ 21 символа (проверяет `i18n.test.ts` автоматически). Тон — съёмочная площадка, без падежей/рода у имён. Мем-формулу источника переделай под игру («Правило 1: не светись»).
- en: своя игра слов, не дословный перевод; тот же лимит.

const PROPS: PropSet = { fountain: () => [c, 34, 34, 4], /* … */ };
const POSES: Pose[] = [{ view: 'D', patch: (m) => { /* предмет в руках */ } } /* … */];
const ACTS: Look['acts'] = { freeze: { poses: [0], ms: 1000 }, jump: { poses: [1, 2], ms: 250 }, dance: { … }, wave: { … } };

Изнанка — второй элемент `looks` (тот же набор полей). `subliminal: true` — гэг «25-й кадр»: в обычном облике раз в 6–12 с на ~140 мс мелькает фигура из изнанки, а изредка (30%) на 80 мс «вклеивается» кадр изнанки целиком. Не заданное поле берётся из парка.

Регистрация: строка `<id>: () => import('./<id>')` в `LOADERS` в `themes/index.ts` (тип требует запись для каждого `ThemeId`). Пакет попадёт в отдельный файл сборки — бюджет ~15 КБ.

### 4.1 Костюм толпы (12×16, шаблон в `sprites.ts › HEAD/BODY/LEGS`)

Строки 0–8 голова, 9–12 тело, 13–15 ноги; столбцы 0–11; виды `D` (к нам), `U` (спиной), `S` (боком, лицом вправо; влево — отражение).

| Буква | Что | Буква | Что |
|---|---|---|---|
| `o` | контур (оставь `PAL.ink`) | `b` / `B` | одежда / её тень и низ |
| `h` / `H` / `k` | верх головы: волосы или шапка / тень / блик | `v` | перёд торса (D: 4 пикс. по центру, строки 10–11) |
| `r` / `R` | затылок/бок головы / тень | `a` | руки (рукава или кожа) |
| `s` / `S` | кожа / тень кожи | `l` / `L` | штаны / обувь |
| `e` `m` `c` | глаза, рот, щёки | `w` `d` | блик, капля пота |

Свои буквы (галстук `t`, бейдж `n`, фингал `x`…) — в `map` и ставь их в `patch(m, view)`: `m[строка][столбец] = 'буква'`. Патч применяется до сдвига кадра танца, поэтому шапки и шлемы едут вместе с головой (см. шлем в `moon.ts`, колпак в `kitchen.ts`, галстук в `office.ts`).

**Разная толпа** (по желанию, особенно в изнанке): `variants: CharStyle[]` в облике — ещё костюмы; фигуры получают их по очереди по порядковому номеру в мире (`variantOf`), поровну и вперемешку, одинаково у ботов и игроков — никого не выдаёт. Позы общие для всех костюмов. Разнообразь силуэт (капюшон, лысина, повязка), одежду и тон кожи (`peach`, `tan`, `fawn`, `brick`). Образец — `FIGHTERS` в `office.ts`. **Если у темы два облика — фигура i остаётся тем же человеком в обоих**: та же кожа и волосы, меняется только одежда (общий список людей `PEOPLE` + `face(i)` в `office.ts`, одинаковое число костюмов в обоих обликах), иначе светлый клерк «превращается» в темнокожего бойца.

Сходство на 12 пикселях: **одна крупная деталь силуэта** (головной убор, причёска-цвет, торс) + **одна мелкая метка** (галстук, бейдж, пояс). Толпа должна сливаться между собой, но отличаться от земли: проверь контраст костюма и пола. Красный/синий/жёлтый/зелёный — цвета обводки игроков, не делай костюм целиком в один из них.

### 4.2 Локация (арена 180×260, раскладка общая — меняется только облик)

`ground(arena)` рисует всю арену: стена сверху 12 пикс. (`y 0–11`), бортики по бокам 4 пикс., низ 3 пикс.; центральный круг — `centerDist(w, x, y) ≤ 37` (кайма 37–40) вокруг (90, 132), там стоит главный предмет. `hash(x, y)` — детерминированный шум для текстур (никакого `Math.random`). Только цвета `PAL`, без полупрозрачности на земле — дизеринг шахматкой.

Предметы — **ровно тех размеров и числа кадров**, что в парке (их следы и столкновения в game-core):

| `kind` | Кадр, пикс. | Кадров | Где | Анимация |
|---|---|---|---|---|
| `fountain` | 34×34 | 4 | центр (90, 144) | смена раз в 180 мс — огонь, вода, экраны |
| `tree` | 22×30 | 1 | 4 угла | — |
| `lamp` | 9×26 | 2 | 4 точки вокруг центра | смена раз в 900 мс — мигание |
| `benchH` | 22×10 | 1 | над и под центром | — |
| `benchV` | 9×24 | 1 | слева и справа от центра | — |
| `stall` | 34×30 | 1 | левый верх у стены | — |
| `planter` | 32×13 | 1 | правый верх, оба нижних угла | — |

Предмет рисуется низом на свою точку (x по центру). Главная икона сеттинга — в `fountain` (центр, анимация) и `stall` (крупный). `wall()` — плитка 8×8 стенки сужающейся зоны. `critter(pigeonFrames)` — 6 кадров 6×6: 0–1 стоит, 2–5 убегает (можно перекрасить голубя через `critterSheet(pigeonFrames, map)` или нарисовать своего зверька).

### 4.3 Музыка (`music.ts`)

- Простой путь: `flavor` — общий мотив игры в новом характере: `transpose`, `bpm` (100–140), `swing` (0–0.3), тембры `lead`/`bass` (`sine | triangle | square | sawtooth | pulse`), `arp`, `echo`.
- Сходство с жанром — своя `song: Song`: `step(api, st)` вызывается каждую шестнадцатую. `st`: `s16` 0–15, `bar`, `t`, `dt`, `intensity` 0–2 (конец раунда), `twist`, `barsSinceTwist`. `api`: `voice(type, midi, when, dur, vol)`, `kick(when, vol?, from?)` (`from` 130–260 — томы), `hit(dur, vol, freq, when)` (шум: хэт ~6–8 кГц, малый ~1.2–1.8 кГц, римшот ~2.6 кГц коротко, тарелка ~4.5 кГц длинная), `power(midi, when, dur, vol, iv?)` (перегруженная гитара: по умолчанию квинтаккорд, `[0, 12]` — соло), `rng()`.
- Не монотонно: делай части по счёту тактов (`bar` или `barsSinceTwist`) — например риф → риф + соло → стоп-тайм со сбивкой → риф октавой выше, сбивки в конце четвёрок, тарелка в начале частей. Инструментально: вместо «голоса» — мелодия гитарой/пульсом. Мелодию изнанки полезно вполголоса показать в обычном облике (узнавание при смене).
- Громкости: бас 0.12–0.18, мелодия 0.04–0.09, перегруз 0.07–0.11, бочка 0.18–0.34. `echo` в `flavor` даёт эхо всем голосам, кроме баса.
- Приметы жанра собирай из: темп, грув ударных (где бочка и малый), длительности баса, тембр лидера, эхо/свинг, динамика по `twist` и `intensity`. Последовательность аккордов — общеупотребимая; мелодия — своя, никогда не подбирай известную.
- Изнанка в музыке = смена подачи (тихо → громко, мажор → минор, темп), тарелка на `barsSinceTwist === 0 && s16 === 0`.
- «Море волнуется» ставит песню на паузу и потом продолжает её с той же ноты — само, ничего писать не нужно; шаг песни должен зависеть только от `bar`/`s16`/`barsSinceTwist`, без своего скрытого счётчика.

### 4.4 Свои действия: позы, анимации, иконки команд

У каждого облика (`looks[i]`) — свои занятия толпы (образец — `OFFICE_POSES`/`BASEMENT_POSES` в `office.ts`):

- `poses: Pose[]` — свои кадры 12×16: база `{ view, legs?, arms?, face? }` + `patch(m)` поверх костюма (`m[строка][столбец] = 'буква'`; предметы — своими буквами в `chars.map`: кружка, сигарета, скакалка…). Лента: общие кадры, затем позы (`F.COUNT + i`).
- `acts: { freeze?, jump?, dance?, wave?, jab? }` → `{ poses: [индексы поз], ms, flip?, yoff? }` — какие позы крутятся во время действия. `freeze` — команда «замри» (одна поза: все «делают вид»), `jump`/`dance` — команды и эмоции, `wave` — эмоция. Чего нет — общий кадр.
- `icons: { freeze, jump, dance }` — иконки 8×8 на кнопках и над полем во время команды (буквы и цвета — `ICON_MAP` в `sprites.ts`).
- Названия команд — `themeText.crowd` / `twistCrowd` (§3).

Правила хорошей позы: предмет контрастен костюму (на белой рубашке — красная кружка, на коже — белые бинты), поднятая рука убирает опущенную (`b`/`B` на её месте), действие читается в 2–4 кадрах. Проверь лист поз крупно (×8) до запуска игры — нарисуй его маленьким скриптом через esbuild + Playwright, как `og-entry.ts`.

### 4.5 Флаги пакета для особых эффектов (уже реализованы — просто включи)

- `transition: 'dusk'` — плавная смена облика (закат/рассвет: золото → лиловый → облик меняется на пике сумерек → проступает), без мигания и щелчка; музыка переключается на границе такта. Обязательно вместе с `twist.quietSec: 3` в game-core — пока идёт закат, «Море волнуется» не начинается. Образец — `miami.ts`. По умолчанию — `'flicker'` (свет мигнул, как в «Клерках»).
- `starSiren: true` — подобрал звезду: мигалка красно-синим и сирена («звёзды розыска»).
- `pulse: { colors, ms, alpha }` в облике — поле пульсирует цветами в такт (ночной клуб; `ms = 60000 / bpm`).
- `subliminal: true` — «25-й кадр» (см. §4).
- Люди для разной толпы — `themes/people.ts` (`PEOPLE`, `face(i)`, `skin(i)`): общие для всех тем; костюмы облика в том же порядке.
- Палитра: `PAL.magenta` — это **красный** (#ff0044), а не розовый неон; для розового неона бери `PAL.orchid`. Красный/синий/жёлтый/зелёный — цвета обводки игроков, ими не красить крупные части костюмов.

### 4.6 Эффекты на поле (уже есть, ничего писать не нужно)

Событие `twist`: мигание света, щелчок выключателя, лёгкая тряска, тост `twistOn/twistOff`, `audio.setTwist`. Облик меняется по `World.twist` того мира, что на экране, — повтор на разоблачении и клип покажут изнанку там же, где она была. Новый эффект для конкретной темы — флагом в `ThemePack` (как `subliminal`) и обработкой в `scene.ts`, не проверкой id темы.

Готовые скрипты:

```bash
pnpm --filter web theme-sheet <N> <файл.png>   # лист ×8: костюм в общих кадрах, свои позы, иконки — по каждому облику
pnpm --filter web theme-video <N> <файл.mp4>   # видео дубля со звуком игры (нужен запущенный сайт и ffmpeg), ~1,5 мин
```

Сначала **лист** (`theme-sheet`) — смотри его, пока не читается каждая поза и иконка; это быстрее, чем ловить действие в игре.

Потом Playwright (Chromium, `p.devices['Pixel 7']`): `http://localhost:3124/sandbox?dev&theme=<N>&speed=2`, `page.tap('.kto-play')`, сцена — `window.__kto.game.scene.getScene('game')`. Сними:
1. обычный облик на старте игры (`sim.phase === 'play'`), `lookKey` должен быть `<N>_0` с первого кадра;
2. изнанку — дождись `sim.world.twist === true`, кадр сразу (мигание) и через 1.5 с;
3. команды «Море волнуется» в каждом облике: стоп-кадр (`sim.world.isFrozen()` — своё название и иконка) и толпу через ~0.5 с после `crowd.resumeAt` (свои позы); эмоции — когда у 3+ сущностей `act` в `wave|dance|jump`. Замедляй `init0.timeScale = 0.01`, обрезай 1:1;
4. полный матч до `match_end` на `speed=8` без ошибок в консоли; изнанка ни разу не включилась между `crowd.showAt` и `crowd.windowEnd`; затем без `theme` — случайные темы, все `lookKey` встречаются.

В конце запиши `theme-video` и пришли владельцу — музыку ты сам не слышишь, он услышит.

Смотри обрезки в масштабе 1:1: читается ли типаж, не сливается ли толпа с полом, нет ли квадратных пятен шума, не налезают ли предметы на соседние следы. Спроси себя: **узнал бы владелец сеттинг за две секунды без подписи?** Если нет — добавь сигнатуру из таблицы §0, а не деталей «вообще».
