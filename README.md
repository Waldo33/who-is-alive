# «Массовка» · Be Nobody

Браузерная реалтайм-игра для компании: 2–4 игрока, только телефоны, без регистрации — по ссылке, QR или прямо в Telegram.

На пиксельной площади 32 одинаковых человечка. Почти все — боты, остальные — актёры, то есть игроки. Каждый прячется в толпе, вычисляет актёров по поведению и бьёт первым: удар по актёру выбивает его из кадра, удар по боту оглушает и раскрывает тебя самого. Три звезды — победа в дубле. Время от времени «Море волнуется»: музыка обрывается, мир замирает, и надо успеть сделать то же, что толпа. Вырезанные за кадром ставят метку «?» на того, кого считают актёром, а в конце дубля — разоблачение с повтором и награды. Матч — до 8 очков, около пяти минут.

**Играть:** https://benobody.app · с ботами, без сети — `/sandbox` · обучение — `/learn`.

## Что есть в игре

- **Площадки (темы).** Каждый дубль снимается в своей теме — свой костюм толпы, локация, музыка и команды: Кепки, Повара, Пингвины, Космонавты, Клерки, Туристы (ночь Майами), Корпоратив. У части тем есть «изнанка» — посреди дубля гаснет свет, и толпа меняет облик и повадки. Скрытая тема «Купальская ночь» — хоррор с потерей рассудка, кикиморами и Лешим, победа за последним выжившим.
- **Условия съёмки** — особые правила дубля: «Жёсткий дубль», «Один удар», «Звездопад», «Шквал команд».
- **Клип «Лучший момент»** выбывшего и **«Фильм матча»** — короткие ролики со звуком, которые можно выгрузить и отправить в чат.
- **Лобби и комнаты** с зрителями (кто опоздал к матчу), переподключение, PWA, Telegram Mini App, русский и английский.

Художника и композитора нет: **весь арт и звук сделаны кодом** — процедурные спрайты из палитры в 32 цвета и синтез на Web Audio. Шрифт — Press Start 2P (OFL).

## Устройство

Монорепозиторий на pnpm, TypeScript strict.

| Где | Что |
|---|---|
| `packages/game-core` | Правила игры: чистый детерминированный TS без DOM, сети, `Math.random` и `Date.now`. Одно зерно — один и тот же матч. Темы, условия съёмки, боты, ИИ, поиск лучшего момента, словари ru/en. |
| `packages/net` | Сетевой слой: протокол (zod), `HostSession` поверх матча, `RemoteSession` у игрока (прогноз своего персонажа и сверка), клиент `ServerLink` поверх WebSocket. |
| `packages/assets` | Палитра и цвета игроков. |
| `apps/web` | Next.js 15 (App Router) + Phaser 3: страницы, сцена, HUD, звук и музыкальный секвенсор, пакеты тем (грузятся по требованию), клип, карточка результата, превью ссылок, PWA, Telegram Mini App. |
| `apps/server` | Свой игровой сервер на Node: комнаты, лобби и матчи (матч считает сервер, никто из игроков не знает, кто из толпы живой), анонимный вход, аналитика в Postgres, Telegram-бот, монтаж видео. |
| `apps/server/native` | Монтаж клипов и «Фильма матча» на Rust (модуль для Node через napi): растр кадров, текст, перевод в YUV и кодирование через ffmpeg. |
| `infra/` | Terraform, Ansible, скрипты выкладки, наблюдение и панели Grafana. |

### Монтаж клипов и фильма на сервере

Сцены клипа и фильма — общий код с телефоном (`apps/web/src/game/clip.ts`, `film.ts`): они рисуют через интерфейс Canvas 2D. На сервере вместо настоящего холста подставляется `film-native.ts` — он записывает команды рисования в буфер и одним вызовом на кадр отдаёт их Rust-модулю, который делает дорогое: заливки, спрайты, текст, масштаб, YUV и передачу кадров в ffmpeg. Звук сводится через `node-web-audio-api`. Монтаж идёт в отдельном процессе, чтобы не мешать матчам. Если нативного модуля нет, сервер монтирует запасным путём через `@napi-rs/canvas`, а если сервер занят — клип пишет сам телефон.

## Инфраструктура

- **Серверы** — Timeweb Cloud, Европа (Нидерланды): игровой сервер и сайт (Next standalone за Caddy), Postgres, отдельная машина для Telegram-бота и наблюдения (VictoriaMetrics, VictoriaLogs, Grafana, сторож с тревогами в Telegram).
- **Terraform** (`infra/terraform`, [docs/terraform.md](docs/terraform.md)) описывает сами машины: тарифы, ОС, адреса. План показывается в PR, применение — кнопкой `infra-terraform`. Файл состояния не хранится: перед каждым планом серверы подхватываются из живого Timeweb.
- **Ansible** (`infra/ansible`, [docs/ansible.md](docs/ansible.md)) настраивает машины изнутри ролями: система, Postgres, приложение и Caddy, туннели, ffmpeg, наблюдение, сторож. На PR — сухой прогон против прода.
- **Выкладка — GitHub Actions.** Каждый push в `main` выкатывается в прод: `web-deploy` (сайт) и `game-deploy` (игровой сервер: Ansible → сборка Rust-модуля → `setup.sh`). Серверы меняются только после зелёного CI того же коммита. Выкладка синяя/зелёная: новая версия поднимается рядом, лобби переезжают к ней, начатые матчи доигрываются на старой — игроки ничего не замечают. В конце `game-deploy` гоняет живой прогон четырёх игроков против прода. Стоп-кран — переменная репозитория `DEPLOY_FREEZE=1`.
- **Секреты** рождаются на сервере или приходят из GitHub Secrets; в репозитории их нет.

## Запустить локально

Нужны Node 22 и pnpm 10 (`corepack enable`). Для Rust-модуля — cargo, для видео — ffmpeg; без них всё остальное работает.

```bash
corepack enable && pnpm install
pnpm dev                                  # сайт: http://localhost:3000, песочница с ботами — /sandbox
pnpm --filter @kto/server dev             # игровой сервер локально (без базы — аналитика в памяти)

pnpm lint && pnpm typecheck && pnpm test  # то же, что CI
pnpm sim -- --rounds 1000                 # безголовая симуляция с проверкой инвариантов
pnpm --filter web build                   # прод-сборка сайта
pnpm --filter @kto/server build:native    # Rust-модуль монтажа (нужен cargo)
pnpm --filter web standalone              # песочница одним HTML-файлом: apps/web/dist/sandbox.html
```

В песочнице: `?dev` — панель настроек, `?dev&speed=8` — ускорение времени, `?dev&theme=N` — все дубли в одной теме, `?lang=en` — английский.
