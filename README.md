# «Кто тут живой?»

Браузерная реалтайм-игра на 2–4 игроков с телефонов: прячься в толпе одинаковых пиксельных ботов, вычисляй живых и бей первым.
ТЗ: Claude Doc «Кто тут живой? — ТЗ для разработки».

## Статус по плану (раздел 17 ТЗ)

| Этап | Статус |
|---|---|
| 1. Каркас | готово в коде: монорепо pnpm, Next.js, Phaser, CI, клиент Supabase с анонимным входом. Осталось: создать проект Supabase и подключить репозиторий к Vercel |
| 2. Игра на одном устройстве | готово: `game-core`, песочница с 3 ИИ-игроками, все фазы раунда, тесты и безголовая симуляция |
| 3–8 | впереди |

## Быстрый старт

```bash
corepack enable          # pnpm 10
pnpm install
pnpm dev                 # http://localhost:3000 → «Играть с ботами»
pnpm test                # юнит-тесты game-core (Vitest)
pnpm sim -- --rounds 1000  # безголовая симуляция с проверкой инвариантов
pnpm --filter web standalone  # apps/web/dist/sandbox.html — песочница одним файлом
```

Дев-режим песочницы: добавь `?dev` к адресу — панель правки конфига на лету; `?dev&speed=4` ускоряет время.

## Языки

Русский и английский («Who’s Alive?»). Все тексты — в `packages/game-core/src/locale/` (`ru.ts`, `en.ts`, одинаковая структура проверяется типом и тестом, длина строк для canvas — тоже тестом). Язык выбирается по устройству, переключается на стартовом экране, для проверки — `?lang=en`.

## Структура

- `apps/web` — Next.js (App Router). `src/game/` — сцена Phaser, процедурные спрайты-заглушки, битмап-шрифт, звук, оболочка песочницы.
- `packages/game-core` — правила без зависимостей от Phaser и сети: арена, A*, боты, удары, звёзды, «Море волнуется», сужение, очки, награды, ИИ-игроки, журнал событий и повтор.
- `packages/net` — интерфейс `Transport`, локальная петля, zod-схемы намерений. Реализация на Supabase Realtime — этап 4.
- `packages/assets` — палитра 32 цвета.
- `supabase/` — миграции появятся на этапе 3.

## Деплой на Vercel

Root Directory: `apps/web`, Install Command: `pnpm install`, Framework: Next.js. Переменные — в `apps/web/.env.example`.

## Решения, отличающиеся от ТЗ

- «Море волнуется» — стоп-кадр: мир замирает и сереет на 1,5 с (детский режим 2,5 с), нажатие в паузе выполняется вместе с толпой; после паузы ещё 1 с можно нажать, но это опоздание видно всем. Время раунда на паузу не тратится.
- Чудачества ботов: изредка (≈2–3 эпизода за раунд, `botQuirkPerMin`) бот ведёт себя как живой — суетится, ходит за кем-то, бежит к звезде, спамит эмоции или опаздывает на «Море волнуется». Ложный след: удар по такому боту — оглушение.
- Разоблачение длится 12 с (барабан 1 с + повтор 20 с ×2,5 = 8 с + финальный кадр 3 с) вместо 8 с: иначе повтор не помещается. Параметры `reveal*` в конфиге.
- Звуковые эффекты пока синтезируются собственным модулем; ZzFX и финальная музыка — этап 7.
- Шрифт Press Start 2P берётся из `@fontsource/press-start-2p` (OFL), без запросов к Google Fonts.

## Баланс по симуляции

При `scoreToWin: 5` из ТЗ матч кончался в среднем за 2 раунда. Поднято до 8: около 3,5 раунда и ~5 минут с ИИ-игроками (живые игроки, скорее всего, будут дольше). Порядок тем перемешивается в каждом матче и реванше.
